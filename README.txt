LOVEMASK WEBSITE — UPDATED VERSION

Preview:
1. Extract this ZIP file.
2. Open the lovemask_website folder.
3. Open index.html in a browser.

The homepage is a responsive static website. It links to:
- Scribble Hub: Beneath the Jade Skies
- Substack: Lovemask Moments

The Fiction & Novels section is deliberately genre-neutral. Beneath the Jade Skies
is shown as one featured title, while the layout has room for future work in any
genre: romance, mystery, contemporary fiction, science fiction, fantasy, short
stories, and more.

The site is not online until you publish it using a hosting service. Free static
hosting options include GitHub Pages and other static-site hosts; account age
requirements and terms vary, so ask a parent or guardian to help check eligibility
and set up hosting if needed.

To add a new story later, duplicate the existing work-card markup in index.html
and replace the title, description, genre labels and destination link.
